# Cloudflare Pages + Supabase App

## Setup
1. Create a Supabase project and run the SQL below to create the `tasks` table.
2. In Cloudflare Pages, set these build settings:
   - Build command: `npm run build` (or leave empty)
   - Publish directory: `public`
   - Functions directory: `functions`
3. Add these environment variables in Cloudflare Pages > Settings > Environment variables:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`

## Supabase SQL
```sql
create table tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
alter table tasks enable row level security;
create policy "public read" on tasks for select using (true);
create policy "public insert" on tasks for insert with check (true);
create policy "public delete" on tasks for delete using (true);
```
